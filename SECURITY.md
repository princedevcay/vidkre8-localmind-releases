# Reporting a security problem

If you find a security problem in VidKre8 LocalMind, in the model list, or in an engine build published here, please report it privately. Use **Security → Report a vulnerability** on this repository: <https://github.com/princedevcay/vidkre8-localmind-releases/security/advisories/new>.

Please don't open a public issue for it.

- You'll get a reply within 7 days.
- A bad item in the model list is withdrawn with a new signed list, which the app picks up by itself.
- Only the latest app version and the latest signed list are supported.
